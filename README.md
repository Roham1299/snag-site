# snagdl.com

The website for [Snag](https://github.com/Roham1299/snag): one static page, served by Cloudflare
Pages from this repository. Nothing to build; push to `main` to publish.

The download buttons find their files in Snag's latest GitHub release (`download.js`).
`_headers` sets the security headers Cloudflare Pages sends.

Screenshots come from the app's preview mode (`npm run dev` in Snag's `frontend/`, then
`/preview.html?subscriptions` and `/preview.html?playlist`).
